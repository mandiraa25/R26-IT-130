# Grade 3 Sinhala listening recordings

Copy your 20 Sinhala MP4 files directly into this folder:

| Level | Filenames (questions 1–5) |
| --- | --- |
| 1 | `g3_l1_g3_1.mp4` through `g3_l1_g3_5.mp4` |
| 2 | `g3_l2_g3_1.mp4` through `g3_l2_g3_5.mp4` |
| 3 | `g3_l3_g3_1.mp4` through `g3_l3_g3_5.mp4` |
| 4 | `g3_l4_g3_1.mp4` through `g3_l4_g3_5.mp4` |

Select Sinhala in the app. Listen plays only the audio of the matching MP4;
Show question appears after it ends. Listen again replays the recording.
Each file should contain that question's instruction sequence and pauses,
without revealing its answer. These files do not replace How to Play videos.

Playback works with background music muted. Missing or unsupported recordings
use the existing Sinhala text-to-speech. English, Grades 2/4, scoring and
progression keep their existing behavior until separate recordings are added.

The mapping is in `src/features/workingMemory/config/instructionAudio.js`.
No source changes are needed after copying the files here.
