# Jungle journal artwork

Generated with the built-in imagegen tool using the supplied Learning Reports
reference. Final selected PNGs are used by the report navigation screens only.

| File | Size | Purpose |
| --- | --- | --- |
| `journal-board.png` | 1627 × 967 | Blank parchment journal, wooden rim, binder pins and corner leaves; transparent outside. Final refinement reduces the bottom-right leaves to keep buttons clear. |
| `wooden-disc.png` | 512 × 512 | Blank circular wood control with transparent exterior. Home, magnifier and chart icons are rendered over it in React. |

`generation-prompts.json` records the exact prompts and source filenames.
The disc was resized from its generated source; PNG alpha is preserved.
Existing matching jungle background and mascot portraits remain in the parent
`images/reports/` folder. No text or report data is baked into these assets.
