# Working Memory image review

These 28 files are preserved outside public for the user's review. No files were permanently deleted.

The [manifest](manifest.csv) lists every original path, review path, SHA-256 and reason.

Five Grade 3 images are not generated by any current question in either language. The remaining files duplicate byte-identical artwork within the same grade and level; all affected questions now use the retained image.

Evidence: all 120 generated Picture Memory questions were enumerated (Grades 2–4, Levels 1–4, five questions, English/Sinhala); direct source, data, CSS, scripts and test references were searched; sprite and dynamic path construction were checked. Source PNGs used for WebP conversion and uncertain legacy assets remain in the public hierarchy.
